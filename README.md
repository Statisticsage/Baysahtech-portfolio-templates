## How to Use

**Option A — Download one file**
1. Click the template file above (e.g. `orbital.html`)
2. Click the **Raw** button
3. Right-click anywhere on the page → **Save As** → save as `index.html`
4. Open in your code editor, replace the placeholder text with your own info
5. Done — host it anywhere (GitHub Pages, Vercel, Netlify)

**Option B — Clone everything**
```bash
git clone https://github.com/statisticsage/Baysahtech-portfolio-templates.git
```

## Quick Customization

Every template has CSS variables at the top of the file. Change these first:

```css
:root {
  --accent: #4f8ef7;   /* your brand color */
  --bg: #050b18;       /* background */
}
```

Then find and replace the placeholder name, email, and links throughout the file.

## Templates

### Orbital — Developer / Engineer
Dark space theme with animated star field, orbit ring graphic, and scroll reveals. One signature animation, everything else is calm and professional.

### Editorial — Product Designer
Off-white magazine layout with big serif typography. Projects displayed as editorial rows. Cursor expands into a reading circle on hover over text.

### Terminal — Systems / Backend Engineer
Pure monospace CLI aesthetic. Nav shows a shell prompt, projects displayed like GitHub repos, skill bars animate on scroll. No color except green on black.

### Studio — Freelancer / Creative Director
Full-bleed case study layout with a page loader and magnetic cursor that appears over project images. For freelancers who want to look like a studio.

### Precision — Engineering Manager / PM / Senior Leader
12-column Swiss grid, pure typographic hierarchy, no decoration. Work presented as a scannable table. For senior professionals who want to be taken seriously immediately.
