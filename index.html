How to use a template

Four steps. Under 5 minutes.

step_01

Pick your template

Hit Live Preview on any card above. Browse the full template in your browser before committing to it.

step_02

Download the file

Click Download → hit the Raw button → right-click the page → Save As → index.html

step_03

Edit your info

Open in any editor. Change the name, title, projects, links. Edit :root CSS variables at the top to change colors in one place.

step_04

Deploy anywhere

Upload to GitHub Pages, Vercel, or Netlify — all free, all support a single HTML file with zero config.
